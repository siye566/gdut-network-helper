# 广工校园网助手

面向广东工业大学大学城校区，从 `gdut-宿舍号` 切换到 `gdut` 后重复网页认证的场景。第一版 Flutter 源码，覆盖 Windows、macOS、Android、iOS 的界面和认证核心；当前还不是安装包。

## 已实现

- 网络变化防抖、30 秒状态检查、切网中止旧操作；同为 Wi-Fi 的切换也能由定时检查覆盖。
- 从学校真实页面读取当前设备 IP、动态配置和认证状态，按核实的 Dr.COM 协议构造登录。
- 账号放系统安全存储，提供保存、清除、手动认证和自动认证开关。
- 安卓请求明确绑定 Wi-Fi，不误走移动数据；手机同意学校服务协议由用户主动勾选，每次重新打开不保留同意状态。
- 超时有限重试；明确认证拒绝后停止自动提交，重新核对并保存账号后才能恢复。
- 套餐仅查询，不开通；验证码、未知模板、配置变化交回官方网页。

## 现在可以直接用的只读诊断

电脑装有 Node.js 18+，连接校园网后，在本目录运行：

```powershell
node tool/inspect.mjs
```

只访问学校入口和状态接口，不提交账号、不登录、不注销。它输出门户是否可识别、认证状态和能否读取动态 IP，不输出账号、姓名或 MAC。

## 启动应用源码

先安装 Flutter stable（最低 Flutter 3.35 / Dart 3.9）、Node.js 18+ 及目标平台的开发工具，然后在本目录运行：

```powershell
node tool/bootstrap.mjs
flutter pub get
flutter run -d windows
```

`bootstrap` 在临时目录生成官方原生工程，只复制缺失的平台目录，不覆盖本项目业务源码、依赖配置和已有平台目录，不创建交付测试，不编译。已有原生工程应按 [平台接入说明](docs/platforms.md) 手动核对配置。首次依赖恢复会生成 `pubspec.lock`，应随实际工程提交。

安卓连接开发设备后用 `flutter run`；macOS/iOS 须在 Mac 上安装 Xcode 并配置开发签名。手机首次访问校内地址时如弹出本地网络授权，需要允许。

保存自己账号 → 手机用户查看学校协议并主动勾选 → 点击“检查并认证” → 确认实际登录成功后开启自动认证。

## 平台与当前边界

| 平台 | 本版运行方式 |
| --- | --- |
| Windows / macOS | 程序运行期间检查，最小化可继续；退出后停止。托盘、开机启动尚未实现。 |
| Android | App 打开时自动检查和认证，回前台重新检查；后台服务、锁屏保活尚未实现。 |
| iPhone / iPad | App 打开时检查和认证；后台切网自动触发与快捷指令尚未实现。 |

手机当前仍需要打开助手，尚未完成“切网后完全无操作”的体验。iOS 的系统级热点认证涉及专用 entitlement，详见 [平台限制与官方文档](docs/platforms.md)。

本版使用你提供的大学城门户 `10.0.3.2` 和 `gdut` 无线 AC `172.16.254.2`，设备 IP 每次重读。AC 配置位于 `lib/assistant_controller.dart` 的构造参数；它不是全校固定值，另一 SSID 若使用不同 AC，需要新的认证页跳转来适配。本版尚未实现按 SSID 自动选择多组 AC，也未核实东风路、龙洞或其他校区。学校当前门户使用 HTTP；系统安全存储只保护本机保存的凭据。
